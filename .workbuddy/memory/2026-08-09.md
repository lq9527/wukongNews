## SSH GitHub 公钥认证修复
- 问题:`git push` 报 `Permission denied (publickey)`,GitHub 仓库 `lq9527/wukongNews`。
- 根因:本机有 3 把密钥(`id_ed25519` 旧默认、`id_ed25519_githup` 今天为 GitHub 新建、`id_rsa_gitee`)。`~/.ssh/config` 为空,SSH 默认只用 `id_ed25519`,而 GitHub 注册的是 `id_ed25519_githup`。
- 修复:写 `~/.ssh/config`,映射 `github.com -> IdentityFile ~/.ssh/id_ed25519_githup` + `IdentitiesOnly yes`,`chmod 600`。
- 验证:`ssh -T git@github.com` 返回 `Hi lq9527!`;`git push --set-upstream origin main` 成功。
- 经验:多密钥环境下,github.com 必须用 config 显式指定 IdentityFile,否则默认密钥不对会一直 publickey 拒绝。
